# INSTA Pucón · Ventas

PWA para registrar ventas diarias desde iPhone.

## Publicarla gratis con GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube todos los archivos de esta carpeta.
3. En Settings → Pages, selecciona la rama `main` y `/ (root)` como origen.
4. GitHub publicará la página en una dirección `github.io`. GitHub indica que la publicación puede tardar unos minutos.
5. Abre esa dirección en Safari del iPhone.
6. Pulsa Compartir → Añadir a pantalla de inicio.

Los datos de ventas se guardan localmente en el dispositivo mediante `localStorage`.
